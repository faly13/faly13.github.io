# Portfolio — Faly Manana Nehemia Raheriniaina

Portfolio personnel d'un développeur web junior basé à Mahajanga (Madagascar) : PHP, Laravel, MySQL, JavaScript.

Une page unique, sans dépendance à installer : une intro animée, puis des sections qui défilent à l'horizontale (accueil, à propos, compétences, parcours, projets, formation, contact).

## Contenu
- Parcours : stages chez Lovatech (JCI Mahajanga) et à la Commune Urbaine de Mahajanga
- Projets : StockPro, gestion bibliothécaire, agence immobilière
- Site réalisé en stage : Hôtel Coco Lodge Majunga

## Technologies
HTML5, CSS3, JavaScript (sans framework)
